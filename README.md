# BasaMatika - Voice Recognition Setup

Since the speech recognition AI model is too large for GitHub, follow these steps after cloning:

1. Download the Tagalog Vosk Model from [Vosk Models Page](https://alphacephei.com/vosk/models).
2. Extract the downloaded zip file into the project root folder.
3. Rename or ensure the folder is named: `model_tagalog_vr_capstone`
4. Install dependencies: `pip install -r requirements.txt`
5. Run the app: `python main.py`
